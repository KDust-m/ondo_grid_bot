# Ondo Perps 그리드 봇

Python 3.9+ 표준 라이브러리만 사용합니다 (설치할 패키지 없음).

```
cd "$env:USERPROFILE\OneDrive\Desktop\ondo_grid_bot"
py ondo_grid_bot.py
```

1. 거래 페어 입력 — `WTI-USD.P`, `wti`, 또는 거래 화면 URL(`https://app.ondoperps.xyz/trade/perps/WTI-USD.P`) 모두 가능
2. API Key ID / Secret 입력 (화면에 표시되지 않으며, 파일·로그에 저장되지 않음)
3. 신규 시작이면 그리드 간격(%)·배율·주문당 잔액 비율(%)을 입력받고, 기준가·주문 범위·수량을 보여준 뒤 `y` 확인 후 주문 시작
4. 재시작이면 확인 없이 기존 그리드를 이어서 운영 (부족한 주문만 추가)
5. 중지: `Ctrl+C` — 거래소의 주문은 그대로 유지되며, 다시 실행하면 이어서 운영

## 동작
| 항목 | 값 |
|---|---|
| 마켓 | 실행 시 입력한 페어 1개 |
| 그리드 간격 | 신규 시작 시 입력 (Enter = 0.2%), 2% 미만. 재시작 시 기존 그리드 간격 유지 |
| 그리드 | 기준가 × (1 ± 간격 × n), n = 1..50 (위 숏 50개 / 아래 롱 50개, 범위 ±간격×50) |
| 주문 비율 | 신규 시작 시 입력 (Enter = 5%). 한쪽 50개 주문 증거금(비율×50÷배율)이 잔액의 90%를 넘으면 다시 입력 |
| 주문 수량 | 시작 시 1회: 거래 가능 잔액 × 주문 비율 ÷ 시작 가격, 수량단위로 절사. 모든 주문·재진입에 동일 수량 사용. 재시작 시 거래소에 걸려있는 주문 수량을 그대로 이어 씀 |
| 레버리지 | 신규 시작 시 입력 (Enter = 10x, 마켓 최대 배율 이하). `y` 확인 후 적용. 재시작 시 처음 입력한 배율 유지 |
| 발주 속도 | 1초에 1건 |
| 체결 확인 | 30초마다. 체결 수량만큼만 한 칸(그리드 간격) 반대 가격에 지정가 종료 |
| 반복 | 종료 주문이 다 체결되면 그 레벨에 진입 주문 재발주 |

봇 주문은 `clientOrderId` 가 `og_` 로 시작하며, 그 외 주문은 건드리지 않습니다.

## 파일
